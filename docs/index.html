💰 Apa itu Harga Modal (HPP)?

HPP (Harga Pokok Penjualan) adalah harga modal / biaya untuk membuat atau membeli 1 pcs produk tersebut (belum termasuk ongkir/iklan/biaya Shopee — itu semua sudah otomatis dihitung Shopee di "Total Penghasilan").
Untung dihitung dengan rumus: Untung = Total Penghasilan − HPP.

💾 Simpan / Buka Daftar Harga Modal (file CSV)

Daftar HPP Anda tersimpan sebagai file CSV yang Anda simpan sendiri (di laptop, Google Drive, dll) — bukan di server manapun. Buka file itu lagi lain kali dengan tombol "Unggah CSV" di bawah supaya harga-harga lama Anda muncul lagi.

Catatan: "Unggah CSV" akan mengganti seluruh daftar HPP yang sedang tampil dengan isi file tersebut.
